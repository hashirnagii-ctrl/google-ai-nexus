# Google AI Nexus

An interactive 3D showcase of Google's AI ecosystem, coded by Hashir Nagi.

Built with React, Vite, Tailwind CSS, React Three Fiber, and Framer Motion.

## Features

- **AI Active Fleet** — explore Google's AI tools (Gemini, NotebookLM, Antigravity, Flow & Whisk, Vids) with pros/cons cards and a reactive 3D nexus ring
- **AI History** — a timeline of Google's AI milestones from Google Brain (2011) to Gemini 3.5 (2026)
- **8D Audio Lab** — a Web Audio API spatializer that pans "Naazni" across the stereo field in a continuous sine wave (use headphones!)

## Getting Started

```bash
npm install
npm run dev
```

> **Note:** `public/audio/naazni.mp3` currently contains a placeholder tone. Replace it with the actual Naazni MP3 for the full 8D experience.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run oxlint
